# Streamline Player v3

Расширенная Android-основа музыкального плеера.

## Уже добавлено

- фоновые аудио через Media3/MediaSession;
- отдельные разделы «Медиатека», «Скачанные» и «Google»;
- импорт одного или нескольких MP3 с телефона;
- кнопка «Прикрепить MP3» для собственного файла;
- локальный список офлайн-файлов;
- экран Google Sync и каркас YouTube OAuth;
- контракт синхронизации плейлистов и добавления видео в плейлист.

## Сборка на телефоне

1. Установите AndroidIDE.
2. Распакуйте архив во внутреннюю память телефона.
3. Откройте `settings.gradle.kts`.
4. Дождитесь синхронизации Gradle.
5. Нажмите Run или Build → Generate APK.
6. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Google/YouTube

Перед реальным входом нужно создать OAuth Client ID в Google Cloud Console и указать package `com.example.streamline` и SHA-1 сертификата. Инструкция находится в `GOOGLE_SETUP.md`.

Синхронизация YouTube выполняется через OAuth и YouTube Data API. Скачивание реализуется для источников, которые предоставляют разрешённую ссылку на аудиофайл; собственные MP3 всегда можно добавить вручную через кнопку прикрепления.

## Локальное хранение

Импортированные и прикреплённые MP3 сохраняются в локальном хранилище приложения и появляются в разделе «Скачанные» после следующего запуска.

## Источники поиска

Для автоматического поиска используется интерфейс `DownloadSource`. Он принимает название и исполнителя и должен возвращать только прямые ссылки на аудиофайлы от подключённого разрешённого источника. YouTube используется для плейлистов и метаданных, а не как источник MP3.

## OAuth

Кнопка «Подключить Google» открывает OAuth PKCE. Перед сборкой замените `YOUR_ANDROID_CLIENT_ID.apps.googleusercontent.com` в `MainActivity.kt` на Client ID из Google Cloud Console. Callback зарегистрирован в AndroidManifest.

## Сборка без расхода трафика телефона

В проекте есть GitHub Actions workflow `.github/workflows/build-apk.yml`. Он собирает APK на серверах GitHub.

1. Создайте пустой репозиторий на GitHub.
2. Загрузите содержимое проекта вместе с папкой `.github`.
3. Откройте вкладку **Actions**.
4. Выберите **Build Streamline APK**.
5. Нажмите **Run workflow**.
6. После окончания откройте запуск workflow и скачайте artifact `streamline-debug-apk`.
7. Внутри будет `app-debug.apk`.

Gradle, Java и Android SDK скачиваются на сервер GitHub, поэтому мобильный интернет телефона на сборку не расходуется.
