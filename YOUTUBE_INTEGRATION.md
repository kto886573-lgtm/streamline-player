# Интеграция с YouTube и Google

Приложение может авторизоваться через OAuth 2.0 и получать через YouTube Data API собственные плейлисты пользователя, элементы плейлистов, названия, авторов, обложки и ссылки на видео. Для синхронизации сохраняются идентификаторы видео и метаданные.

Официальный API не выдаёт MP3/аудиопоток и не разрешает стороннему приложению сохранять аудио или обеспечивать фоновое воспроизведение YouTube-контента. Воспроизведение YouTube должно идти через официальный YouTube player или открытие видео в приложении YouTube. Офлайн-режим Streamline предназначен для локальных файлов и источников, которые прямо разрешают скачивание.

Для полноценной синхронизации потребуются Google Cloud project, YouTube Data API v3, OAuth client для Android с package `com.example.streamline` и SHA-1 сертификата, а также локальный кэш Room.
